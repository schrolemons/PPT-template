# 代码结构讲解

适用于代码库结构、训练结构、评测结构及其运行流程的汇报。先依据当前指定文档与对应版本代码给出规范解释，再在 Notes 中补充适合初学者的通俗解读。用户备注决定展示重点；涉及调用、返回值与张量形状的事实仍须核对来源。

## 模块构成：总览后逐模块展开

先回答“有哪些模块、共同接入谁、各自负责什么”。把每个模块绘制为一个独立、可编辑块，内部填写：原始英文名 → 用户备注的中文职责 → 关键配置或内部组成。连接线表示接入、持有或依赖关系；并列接入同一对象的模块保持并列，不画成依次调用的流程。

总览页介绍模块及组合关系。一页放不下完整备注、内部层级或输入输出时，保留总览，再一个模块一页介绍；不通过缩小字体把所有实现细节塞进总览。详情页说明模块的输入、处理/功能、输出或更新的属性，以及下游用途。外层模块和内部函数保持父子层级。

以下 LeWM 例子是用户确认的讲解组织方式；用于其他代码库时，替换为来源中的实际对象。用于 LeWM 时，也核对当前版本，不把例子当成永久 API 事实。

| 训练模块 | 块内重点 |
|---|---|
| `world_model` | 训练包装层，规定损失与参数更新；其内部 `model = JEPA` 才是真正的计算网络；按备注展开网络、forward、正则项与优化器。 |
| `data_module` | 连接 train / val DataLoader；说明 Dataset 提取样本、DataLoader 选样本并堆 batch、DataModule 接入数据的职责与样本形状。 |
| `trainer` | epoch、梯度裁剪等训练过程控制；说明训练/验证循环及来源支持的保存、记录功能。 |

三个块共同接入 `Manager(module=world_model, data=data_module, trainer=trainer)`；区分构造管理器与随后调用它启动训练。`trainer.fit(...)` 是执行层，不与这三个模块混成平级组件。

| 评测模块 | 块内重点 |
|---|---|
| `world.evaluate()` | 数据与评测任务：dataset、episodes_idx、start_steps、goal_offset、eval_budget、结果位置与 callables 的职责。 |
| `env / world = World(...)` | 环境初始化：env_name、num_envs、image_shape、max_episode_steps；区分环境自身上限与评测执行预算。 |
| `Policy / world.set_policy()` | 策略接入：solver / model、config、process、transform；重点展示模型提供给规划器的代价接口。 |

三个块共同组成 World 评测系统。不要因英文名有括号就把静态组成关系误画为三步执行流程。

## 模型接口：显著强调并界定调用范围

LeWM 评测重点突出 `get_cost`：使用与正文不同的可读代码字体（例如 Consolas），配合加粗或强调色。展示输入当前观测/目标与候选动作、内部 `encode → rollout → criterion`、输出候选代价 `[B,S]`，并说明 CEM 如何使用该输出。

“仅调用 get_cost”应明确限定为“CEM 接入 LeWM 模型的代价接口”。接口内部仍调用编码、预测与比较；Policy 还有预处理和动作缓冲，环境还有物理执行。把 `get_cost` 表述为 LeWM 模型推理优化的核心入口，并追踪内部计算与重复候选评分；不把它说成整个 World 唯一调用的函数，也不未经测量声称它是端到端唯一瓶颈。其他代码库突出经来源核对的相应核心接口。

## 运行流程：外层两部分，内部按顺序展开

在来源支持下，LeWM World 总览分为：

1. `World._evaluate_from_dataset()`：初始化略讲，展示 `reset` 与 `MegaWrapper` 两个环节的输入、功能和结果，形成后续需要的 `World.infos`。注明 MegaWrapper 是包装器组合；区分函数直接返回与写入 World 属性。
2. `World.run(mode="wait") / World.step()`：内部先 `WorldModelPolicy.get_action(self.infos)`（重点），再 `self.envs.step(actions)`，随后更新 infos 并继续决策。

详情按“初始化 → 策略取动作 → 环境执行”连续三页展开。各页在一致位置放跨页小箭头或简短进度链，突出当前环节；承接上一页输出，并明确下一页输入。环境执行后的反馈标明回到策略，区分潜空间预测与真实模拟步进。

策略详情保留层级：准备输入 → 缓冲为空时 CEM 重新规划并通过 `get_cost` 评分 → 选执行片段、展开动作块并入缓冲 → 取动作并还原尺度。缓冲非空时不重新规划，不能画成每个环境步都无条件调用模型。
