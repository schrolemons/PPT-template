# Core Contract: Notes and Sources

## Visible source footer

- Put a precise, readable `Source: ...` footer on every content slide. Include the source file or work, author or organization when available, section or page, and link when applicable.
- Keep the footer attached to the content it supports and inside the template's source area. The cover may omit the footer when it contains no sourced claim.
- Every visible claim, title, number, label, figure, table, example, and conclusion must be traceable through the footer and the slide's `source_refs`.

## PowerPoint Notes

- Every slide must have a complete, directly readable, multi-sentence speaker script in PowerPoint Notes.
- The script explains the slide's purpose, key points, evidence or boundary, and transition to the next narrative unit.
- End every Notes entry with a `[Sources]` block listing the exact sources used by that slide.
- Keep the script and drafting instructions in Notes only. Never leave `口播稿`, `讲稿`, internal prompts, or source-ledger residue on the visible canvas.
