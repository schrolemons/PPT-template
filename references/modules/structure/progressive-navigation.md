# 变化的小目录

## 用途

将章内目录的稳定语义标签附着在该章节的每一张内容页上，并以当前 `section_id` 的高亮显示听众所在位置。它是结构层施加的导航状态，不添加、删除或重排内容模块的内部字段。

## 适用与不适用

适用于已由 `structure-map` 规划、且属于某个章节的内容页。每页均使用同一章节的标签集合、相同几何位置与相同视觉规则；当同一个内容单元拆成多页时，沿用同一 `section_id` 的高亮状态。

不适用于封面、全局总览、章内目录或章节外页面；不用于将长标签改成难以理解的代号来勉强适配空间，也不用于填写研究结论、来源之外的说明或内容字段布局。

## 输入

- 冻结且已同步的 `structure-map`；
- 当前内容页的 `chapter_id`、`section_id`、`page_span`、`navigation_state` 与 `instance_id`；
- 该章按来源/用户顺序确定的完整语义 `label` 列表；
- 内容模块实例的页码与拆页结果。

## 输出

对该章每个内容模块实例应用稳定导航状态：保留相同标签、标签顺序与几何位置，突出当前 `section_id`，并在同一部分的连续拆分页中持续保持同一突出状态。输出只更新统一接口中的 `navigation_state` 与相应的最终 `page_span` 关联，不改变内容模块内部语义。

## 装配位置

导航随章节内容页装配，而不是作为一组单独结构页集中生成：

```text
chapter-agenda(chN) → content instance 1 + progressive-navigation(chN) → content instance 2 + progressive-navigation(chN) → next chapter-agenda
```

因此它只能出现在其对应 `chapter-agenda` 之后、下一章目录之前。禁止先生成所有导航结构页或将其放到内容页之外。

## 页码同步职责

- 从规划器接收当前章节的最终标签集合、当前 `section_id` 与其 `page_span`；
- 内容拆页后，将同一高亮延续到该 `section_id` 的所有新增页面，并仅在下一个 `section_id` 开始时切换；
- 当页码变化时，同步检查页脚页码、章内目录页段和导航活动项所指的实际内容页；
- 始终保持本章标签集合、顺序和几何稳定；空间不足时拆分内容或选择支持完整语义标签的注册表变体，不得改成不透明缩写。

## 失败条件

- 当前高亮与页面所属 `section_id` 不一致，或拆分页失去/错误切换高亮；
- 同一章的标签、顺序或几何位置在内容页之间漂移；
- 为适配空间而用代码、首字母或无法直接理解的缩写替换标签；
- 导航被用在结构页或章节外页面，或脱离内容页集中生成；
- 导航层改写研究内容、内容模块字段、来源、结论或证据边界。

## 核心契约依赖与资产

本模块仅依赖 `core-contract`，并遵循来源忠实、来源与备注、视觉与可读性要求；它不依赖其他结构或内容模块。注册表中的独立模板资产路径为 `assets/modules/progressive-navigation.pptx`。

## 模板占位词

模板资产的待替换文字使用 `分组标题`、`小节标题`、`当前小节`、`页码范围` 等引导字段。高亮只演示导航状态，不以具体研究名充当占位词；实际汇报中必须换成可直接理解的语义标签。
