# 结论介绍

## 用途

把一个已有来源支持的结论内容单元展示为结论、解释与证据边界层次分明的一页或多页。模块只依赖 `core-contract`；不直接调用其他内容或结构模块，不改变章节顺序，不合并相邻小部分，并在完成时返回最终 `page_span`。

## 适用与不适用

适用于汇报已经完成的学习、调查、实验或论文阅读所得的核心结论、实际意义、不同维度综合、来源支持的比较，或需要明确说明何处不能下结论的情况。

不适用于代替研究过程、将推测写成结论、用“未来计划”填补证据空白、仅列未解释关键词，或没有证据支撑的宏大综合。若内容仍需要完整过程或论文解释，应保持为独立内容单元而不是由本模块自行转派。

## 输入与输出

每次消费一个结论内容单元及通用字段：`module_id`（固定为 `conclusion-display`）、`instance_id`、`chapter_id`、`section_id`、`subsection_label`、`narrative_role`、`source_refs`、`page_span`、`navigation_state`。来源输入至少包括：可直接表述的结论、支持结论的原文事实/数据/观察、解释结论成立的来源逻辑、适用条件与证据边界；比较时还包括对象和统一维度。

输出一页或多页来源忠实结论页及最终 `page_span`。通用连接字段向结构层报告归属、导航和页段，不授权结构层改写结论、解释或证据字段。

## 稳定字段顺序与结构连接

所有变体保持：结论标题 → 明确结论 → 来源支持的解释 → 证据/依据 → 适用条件或证据边界 → 可见来源行。`source_refs` 同时覆盖可见结论与 Notes；`chapter_id`、`section_id`、`subsection_label`、`narrative_role`、`navigation_state` 连接结构映射；完成排版后将最终 `page_span` 回写。

## 支持变体

独立模板资产路径为 `assets/modules/conclusion-display.pptx`。

- `three-dimension-synthesis`：用于来源明确支持的三个并列综合维度。三个维度保持同等视觉权重；每个维度按结论、解释、证据简述组织，不能让一项仅剩标签。
- `conclusion-and-evidence`：用于一项中心结论及其最直接的解释和多条证据。可见区清晰分层，不把证据条目写成新的结论。
- `comparison-table`：用于比较本身支撑结论时。比较维度统一、每个单元均有来源，表格下方或相邻区域单列出比较所支持的结论与边界。
- `evidence-boundary`：用于说明已知结论、不足以支持的推断、适用范围或条件差异。边界不是虚弱结论的装饰，而应指向确切来源限制。

## 拆页条件

当三个维度不能保持等权并可读、中心结论同时需要多项不可压缩证据、比较表行列无法阅读、边界说明被压成脚注碎片，或结论/解释/证据无法在视觉上分开时，拆为连续页面。拆分仍属于同一 `instance_id` 和 `section_id`，不能合并邻接子部分或改换章节顺序。

## 来源、Notes 与模块内质检

独立模板资产中的待替换文字使用 `结论标题`、`要点说明`、`证据标题`、`证据说明`、`比较对象`、`比较维度`、`证据边界`、`来源页码` 等引导字段。模板不预填具体研究结论；实际汇报中的结论必须由当前来源直接支撑。

每页必须保留可见来源行。每页 Notes 包含完整可朗读的多句讲稿和 `[Sources]`，依次说明结论是什么、为何原文支持、证据实际能说明什么，以及不能推出什么；不能把讲稿中未证实的话留作隐含结论。

逐页核对：结论、解释、证据和边界是否视觉与语义分离；所有结论是否由对应来源支持；表格维度是否可比；三维综合是否真为三个等权维度；是否没有把相关性、推测或未来工作说成完成结论；文字与表格是否可读；来源、Notes 和最终 `page_span` 是否完整。
